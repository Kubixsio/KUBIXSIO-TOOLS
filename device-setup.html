Klucz urządzenia — STAGING

Ta strona tworzy lokalny klucz i instrukcję SQL. Dostęp nadajesz sam w konsoli Cloudflare D1. Strona nie łączy się z Workerem ani OpenAI.

Użyj panelu w Photopea oraz tej samej przeglądarki i profilu co Kubixsio Tools. Nie używaj trybu prywatnego.

Sprawdzanie miejsca uruchomienia i lokalnej pamięci…

1. Zachowaj token prywatnie

Po pokazaniu możesz zaznaczyć token i skopiować go ręcznie do prywatnego menedżera haseł. Strona nie zapisuje tokenu. Po jej zamknięciu lub odświeżeniu nie da się go odzyskać z klucza.

Wczytano istniejący klucz. Token nie jest przechowywany na stronie — użyj własnej, wcześniej zachowanej kopii. Jeśli go nie zachowałeś, nie zatwierdzaj SQL; najpierw ustalimy bezpieczne odtworzenie dostępu.

2. Zatwierdź urządzenie w D1 STAGING

Skopiuj wyłącznie SQL do bazy kubixsio-focus-point-staging. Zawiera identyfikator, nazwę, skrót tokenu i klucz publiczny. Nie zawiera tokenu ani klucza prywatnego.

3. Sprawdź zapis i lokalny klucz

Oczekiwany wynik: jeden wiersz, registration = ZGODNE, auth_version = 1, revoked_at = null.

Test podpisuje dane lokalnie i sprawdza podpis kluczem publicznym. Nie sprawdza dostępu do serwera.

SQL do późniejszego unieważnienia tego urządzenia

Klucz prywatny jest nieeksportowalny przez Web Crypto. Skrypty działające pod tym samym originem mogą jednak uzyskać możliwość podpisywania. Używaj wyłącznie zaufanych stron i pluginów tego originu.
